# JavaFX Calculator

A simple desktop calculator application developed using Java and JavaFX. The project provides a graphical user interface for performing basic arithmetic calculations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number calculations
- Clear/reset functionality
- User-friendly graphical interface
- Button-based input

## Technologies Used

- Java
- JavaFX
- FXML
- IntelliJ IDEA
